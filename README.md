# 🛡️ Cybersecurity & Ethical Hacking Portfolio

Benvenuto nel mio portfolio di Cybersecurity. Questo repository raccoglie i progetti pratici, le analisi di laboratorio e le ricerche svolte durante il mio percorso di formazione in Ethical Hacking e Sicurezza Informatica.

L'obiettivo di questo portfolio è documentare le competenze acquisite in ambito **Red Team (Offensive)**, **Blue Team (Defensive)** e **Network Infrastructure**.

---

## 📂 Struttura del Repository

### 🔹 [01_Network_Infrastructure_Labs](./01_Network_Infrastructure_Labs)
Progettazione e messa in sicurezza di infrastrutture di rete.
* **Progetti VLAN:** Segmentazione di rete per isolare il traffico.
* **PfSense Project:** Configurazione di Firewall open-source, regole di filtering e routing.
* **Network Design:** Architetture di rete sicure.

### 🔹 [02_System_and_Network_Analysis](./02_System_and_Network_Analysis)
Attività di Blue Team, hardening di sistema e analisi forense di rete.
* **Windows Server:** Configurazione e gestione di ambienti server Microsoft (Active Directory, GPO).
* **Wireshark Analysis:** Analisi profonda dei pacchetti (PCAP) per individuare anomalie e troubleshooting di rete.

### 🔹 [03_OSINT_Reconnaissance](./03_OSINT_Reconnaissance)
Open Source Intelligence e raccolta informazioni.
* **OSINT Project:** Tecniche di ricognizione passiva per mappare la superficie di attacco di un target utilizzando fonti pubbliche.

### 🔹 [04_Offensive_Security_Ops](./04_Offensive_Security_Ops)
Operazioni di sicurezza offensiva e penetration testing.
* **Authentication Cracking:** Tecniche di password recovery e brute-forcing.
* **Metasploit Attacks:** Utilizzo del framework Metasploit per l'exploitation automatizzata di vulnerabilità note.

### 🔹 [05_Advanced_Exploitation](./05_Advanced_Exploitation)
Analisi avanzata delle vulnerabilità e sviluppo di exploit manuali.
* **Web Exploitation:** SQL Injection (DVWA), Cross-Site Scripting (XSS).
* **Binary Exploitation:** Buffer Overflow (BOF) e corruzione della memoria.
* **BlackBox Reports:** Reportistica completa di simulazioni di attacco (Penetration Test Black Box).

### 🔹 [06_Malware_Analysis_Research](./06_Malware_Analysis_Research)
Studio delle minacce informatiche.
* **Malware Analysis:** Analisi statica e dinamica di campioni di codice malevolo per comprenderne il comportamento e gli indicatori di compromissione (IoC).

---

## 🛠️ Tecnologie e Strumenti Utilizzati

* **Network:** Wireshark, PfSense, Cisco Packet Tracer/GNS3.
* **Offensive:** Kali Linux, Metasploit, Nmap, Burp Suite, Hydra, Hashcat.
* **Systems:** Windows Server, Linux (Debian/Ubuntu).
* **Scripting & Labs:** Bash, Python, Ambienti virtualizzati.
